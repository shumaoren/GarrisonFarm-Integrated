# GarrisonFarm 整合测试版使用说明

用于《明日方舟》「卫戍协议·规程·序列Ⅰ」。角标和晋升是两个独立入口。本文以完整 Windows 运行包为例。

## 第一次使用

1. 把完整 ZIP 解压到有写入权限的目录，例如 `D:/Games/GarrisonFarm`。打开能看到四个 BAT 的文件夹，保持 `程序/GarrisonFarm.exe`、`程序/_internal/` 和 `程序/fallback/` 的相对位置。
2. 打开 MuMu，将模拟器分辨率设为 **1920×1080 横屏**。游戏使用中文，主界面和卫戍协议都用默认主题，保留默认的画面缩放。
3. 如果装了 MAA，在 MAA 中确认能连接这个模拟器实例，再停止 MAA 中运行的任务。程序优先读取 MAA 的连接配置和 OCR 模型，找不到或无法使用时会尝试备用连接及内置模型。
4. 进入游戏的「卫戍协议」大厅，让「极速模拟」或「断线重连」可见。首次可以用默认的 CPU OCR 和普通 ADB 触控跑一局。GPU 和增强触控可单独测试。

当前使用环境为 **64 位 Windows 10 或 11**，以 MuMu 为主要测试环境。其他模拟器的兼容性需要实测。遇到程序启动自检提示时，先按提示检查目录、ADB 连接和游戏画面。

| 入口 | 用途 |
| --- | --- |
| `开始刷角标.bat` | 打开角标模式菜单，自动完成极速模拟 |
| `刷晋升.bat` | 刷规程跃升奖章需要的晋升次数 |
| `测试与设置增强触控.bat` | 测试 MuMu SDK，并选择开启或关闭 |
| `测试与设置GPU加速.bat` | 测试 DirectML OCR，并选择 CPU 或显卡 |

## 刷策略角标

1. 双击 `开始刷角标.bat`。按账号的编队情况选择标准或低配，再按目标选择金色或彩色。金色需要同一策略通关 3 次，彩色需要通关 6 次。程序会读取策略的通关次数，达到所选目标的策略会跳过。
2. **标准模式**建议提前配置「自选编队」。Ⅴ阶可配置维什戴尔、斩业星熊、予愿安洁莉娜、赤刃明霄陈、结城理；Ⅵ阶可配置新约能天使、凯尔希·思衡托、望。账号缺少推荐干员时可选低配。
3. **低配模式**可把自选编队留空，使用模式的预设干员。有条件时可在「选配助战」借用适合的技能配置。出现使用前提示时按提示确认。
4. 让程序完成战斗和结算，角标状态到游戏内对应策略页面核对。看到「断线重连」时，角标模式会尝试接着打旧局。

如果只刷可通过快速结算完成的奖章，可以手动把敌人全部放过去，缩短结算时间。角标以游戏统计的通关次数为准。编队和低配助战名单可查 [上游使用说明](https://github.com/FJH3576/GarrisonFarm-Personal/blob/main/使用说明.txt)。

## 刷规程跃升奖章

1. 在卫戍协议大厅双击 `刷晋升.bat`，确保账号能选择「歌利亚」。程序会打开极速模拟、选择歌利亚、确认当前自选编队，并使调度中心全程保持 **Ⅰ级**。
2. 启动时若大厅显示「断线重连」，晋升入口会先尝试**放弃旧局**。想保留这局时，先手动打完再启动。
3. 自然战败后，程序根据本局结算写入已确认的晋升次数，再开下一局。若打到第 9 轮休整，程序会暂时离开战场，回大厅选择「放弃模拟」，按结算页确认的轮次计数。
4. 脚本累计达到默认目标 **200 次**时停在结算页。如果之前手动做过晋升，游戏进度可能更早达标。每隔几局可在游戏内核对「规程跃升」奖章，以游戏记录为准。

休整时如果买牌、部署、售卖或冻结结果无法确认，程序会将原因写到 `程序/farm_logs/run.log`，尝试退出本局并结算已确认轮次。确认是结算页但读不出轮次时，这局不计入脚本累计，随后重开。退出流程无法确认时程序会停下。选牌和摆位详见 [晋升策略](晋升策略.md)。

## 设置加速

### MuMu 增强触控

1. 关闭正在运行的 GarrisonFarm，保持模拟器和游戏开启。
2. 双击 `测试与设置增强触控.bat`。检测只连接 SDK 并读取画面参数。
3. 出现「SDK 连接成功」后输入 `1` 开启。输入 `0` 使用普通 ADB 触控，回车保留现有设置。
4. 开启后支持 MuMu SDK 点按、拖拽与快速截图。若启动时 SDK 初始化失败，程序会回到普通 ADB；运行中原生触控失败时可能直接停止，重新启动前可先关闭增强触控。

同一实例中若官服和 B 服同时打开，把要刷的客户端放到模拟器前台，退出另一客户端后再试。自动检测失败时，可在 `程序/mumu_touch.json` 的 `emulator_path` 填写 MuMu 安装目录，例如 `D:/MuMuPlayer`。

### GPU 加速

1. 关闭正在运行的 GarrisonFarm，双击 `测试与设置GPU加速.bat`。
2. 输入 `D` 测试菜单上的「系统默认 GPU」（DXGI 编号 0），或输入菜单序号测试指定显卡。菜单序号、DXGI 编号和任务管理器的显卡编号可能不同。
3. 看到「OCR 测试通过」后输入 `Y` 保存，下次启动角标或晋升时生效。GPU 自检用样张验证模型加载和文字识别，无需打开游戏。
4. 选择 `0` 可直接切回 CPU，回车可退出设置。自检失败时可以试另一块卡。显卡或驱动变更后若出现 DirectML 错误，从设置入口重新测试并选择显卡，或切回 CPU。 [DirectML 执行提供程序](https://onnxruntime.ai/docs/execution-providers/DirectML-ExecutionProvider.html)

## 停止、更新与迁移

在运行角标或晋升的终端按 `Ctrl+C`，或关闭运行窗口。需要留住本局晋升次数时，等结算和累计日志出现后再停。一次只运行一个 GarrisonFarm，运行时保持模拟器分辨率和游戏画面，避免 MAA、手动点击或其他工具同时控制模拟器。

换版本前先关闭程序，并把新 ZIP 解压到新目录。从旧版的 `程序/` 备份以下文件，再按需复制到新版本同名位置。没有生成的文件可以跳过。

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 记住的 MAA 路径。换电脑后需要重新检测或设置 |
| `mumu_touch.json`、`gpu_settings.json` | 增强触控及 GPU 设置。换电脑或模拟器后建议重测 |
| `strategies_done.json` | 角标入口的本地记录 |
| `promotion_progress.json` | 晋升入口的本地累计。角标或奖章以游戏内记录为准 |
| `farm_logs/` | 旧日志和诊断图，排障时可按需保留 |

## 常见问题

| 问题 | 怎么处理 |
| --- | --- |
| 找不到 EXE、模型或 DLL | 确认下载的是完整 Windows 运行包，整个解压后再双击 BAT。GitHub 自动生成的源码 ZIP 可用于阅读源码和运行晋升策略测试 |
| 连接到了另一个模拟器或设备 | 在 MAA 里确认所选 ADB 地址。确认游戏在该实例前台，并让 ADB 只连接需要运行的设备 |
| 找不到 MAA | 先在 MAA 中完成一次连接。可用记事本检查 `程序/settings.json` 的 `maa_dir`，填写 MAA 所在目录，例如 `D:/Tools/MAA` |
| 进了大厅却识别失败 | 检查 1920×1080 横屏、默认主题、默认缩放和中文界面。关闭遮挡游戏按钮的弹窗后重试 |
| 拖拽失败、停在休整 | 从最后几条 `run.log` 记录核对资金、店铺和部署位。可关闭增强触控后复测。晋升入口会处理可确认的异常，无法确认退出时需要人工处理 |
| 更改设置或启动提示已有实例 | 关闭另一个 GarrisonFarm 运行窗口，等进程退出后重试 |
| 游戏奖章进度比脚本多或少 | 脚本只统计本地确认结算的晋升，打开游戏奖章页核对。换包时检查是否从正在使用的目录迁移了进度 |

反馈问题时请附模式、模拟器版本、分辨率、是否启用增强触控或 GPU，以及 `程序/farm_logs/run.log` 中相关的一段。公开发帖前去掉账号和本机路径。
