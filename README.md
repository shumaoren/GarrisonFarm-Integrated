# GarrisonFarm 整合测试版

## 项目来源

- 原始项目发布于 B 站。 [《利用MAA自动刷取卫戍协议蚀刻章镀层》](https://www.bilibili.com/video/BV1zMWZ6xED1/)
- 轻骑可历#9000 在原始项目的基础上维护 GarrisonFarm 个人优化版。本整合版直接基于个人优化版 v1.2。 [上游仓库](https://github.com/FJH3576/GarrisonFarm-Personal) · [上游 Releases](https://github.com/FJH3576/GarrisonFarm-Personal/releases)

## 功能

用于《明日方舟》「卫戍协议·规程·序列Ⅰ」的 Windows 辅助工具，支持刷策略角标、Ⅰ级店刷晋升和可选的 DirectML OCR 加速。

| 我想做什么 | 从哪里开始 |
| --- | --- |
| 刷策略角标 | 在完整运行包里运行 `开始刷角标.bat`，按菜单选择编队和角标目标 |
| 刷规程跃升奖章的晋升次数 | 在完整运行包里运行 `刷晋升.bat`，使用极速模拟、歌利亚和Ⅰ级店 |
| 准备模拟器、开启加速或排查问题 | [使用说明](整合版/说明/使用说明.md) |
| 了解Ⅰ级店的选牌、部署和售卖 | [晋升策略](整合版/说明/晋升策略.md) |

## 运行环境

使用 64 位 Windows 10 或 11，推荐 MuMu 和 1920×1080 横屏。游戏使用中文界面和默认主题。首次使用可先通过 MAA 确认模拟器能连接，再打开卫戍协议大厅运行对应的 BAT。完整运行包需要整体解压，默认使用 CPU OCR 和普通 ADB 触控。

本仓库提供源码、文档和晋升策略测试。运行游戏流程需要包含匹配 EXE、运行库和 OCR 模型的完整运行包。
